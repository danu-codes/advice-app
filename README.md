# 💡 Advice App (React)

A simple React application that fetches random advice from an API and tracks how many pieces of advice you have read.

---

## 🚀 Features

- Fetch random advice from API
- Loading state indicator
- Count how many advice messages read
- Button disabled while loading
- Simple and clean UI
